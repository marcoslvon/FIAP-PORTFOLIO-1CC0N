## Destaque: Neighborhood Action Dashboard

**Global Solution 2026.2 — case CitizenTech**

Aplicação em Python que registra, organiza e acompanha demandas de melhoria de um bairro simulado (iluminação, acessibilidade, limpeza e conservação de espaços coletivos). O sistema valida os registros, organiza a espera por ordem de chegada, mantém o histórico das alterações e calcula indicadores sobre as necessidades da comunidade.

**Conceitos aplicados:** listas, dicionários, filas, pilhas, matrizes, organização hierárquica, operadores lógicos, funções, laços e leitura de arquivos — tudo em Python básico, sem bibliotecas externas.

```bash
cd 1CC/GLOBAL-SOLUTION-2
python src/sistema.py
```

📄 **Documentação completa:** [`1CC/GLOBAL-SOLUTION-2/README.md`](1CC/GLOBAL-SOLUTION-2/README.md)
